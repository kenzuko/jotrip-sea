# JoTrip Sea

Public-facing Phu Quoc sea experiences website by JoTrip.

> **Người bản địa đưa bạn đi xa hơn điểm đến.**

## Current phase

UI foundation and visual system only. No production cutover, DNS change, WordPress replacement or live booking mutation is included yet.

### Implemented preview routes

- `/` - layered homepage using real JoTrip/Phu Quoc assets where available.
- `/experiences/fishing/` - first service-page visual master.
- `/experiences/snorkeling/` - water/visibility-first page.
- `/experiences/scuba-diving/` - safety/certification-first page.
- `/experiences/private-cano/` - build-your-day flow.
- `/experiences/island-trips/` - shared vs private and time-on-island flow.
- `/experiences/yacht-charter/` - vessel-first flow.
- `/experiences/sunset/` - shorter cinematic time-based flow.
- `/experiences/squid-fishing/` - night/local-experience flow.

### Principles

- Services first, intelligence underneath.
- Real/local copy over marketing adjectives.
- Real assets first; provisional content stays identifiable in source.
- Public site and Fishing Desk remain separate systems.
- Existing `phuquocfishingtours.com` remains untouched during this build.
